# Metro 2033 Redux Next-Gen <img src="docs/images/flag-hu.svg" alt="HU" width="24" height="24"> Magyarítás

<img src="docs/images/borito_kicsi.jpg" alt="Metro 2033 Redux Next-Gen magyarítás – Steam" width="320">

Nem hivatalos magyarítás a **Metro 2033 Redux Steam next-gen Windows-kiadásához**.
Magyar menük és feliratok, az új szövegek fordításával. A fegyvernevek eredeti angol alakban szerepelnek.

A telepítő külön választható összetevőként a főmenü reklámpaneljét is elrejtheti, magyarítás nélkül is.

**Letöltés:** [Kiadások / Releases](https://github.com/Harciropi/metro_2033_redux_nextgen_HUN/releases)

## Telepítés

**Az eredeti magyarítás külön telepítése nem szükséges.** Ez a telepítő minden szükséges magyar nyelvi fájlt tartalmaz; közvetlenül a játékhoz telepítsd.

1. Zárd be a játékot.
2. Indítsd el a `Metro2033Redux_NextGen_HU.exe` fájlt.
3. Ellenőrizd a helyi Steam-adatokból felismert játékmappát, vagy tallózd be kézzel.
4. Válaszd ki a kívánt összetevőket, majd telepítsd őket.
5. A magyarítás használatakor a játékban válaszd az **angol szövegnyelvet** – a menük és feliratok magyarul jelennek meg.

## Módosítás és eltávolítás

Indítsd el újra ugyanazt az EXE-t. Az összetevők külön ki- és bekapcsolhatók, vagy teljesen eltávolíthatók. A telepítő visszaállítja a mentett eredeti fájlokat; sikeres teljes eltávolításkor a saját mentéseit is törli. A játékmentések és személyes beállítások megmaradnak.

Egy játékfrissítés visszaállíthatja a módosított fájlokat. Ilyenkor szükség lehet az összetevők ismételt alkalmazására vagy frissített telepítőre. A régi, legacy játékkiadás nem támogatott, ha azzal rendelkezel a korábbi Lostprophet magyarítást telepítsd.

# Metro 2033 Redux Next-Gen <img src="docs/images/flag-hu.svg" alt="HU" width="24" height="24"> Hungarian Translation

<img src="docs/images/borito_kicsi.jpg" alt="Metro 2033 Redux Next-Gen Hungarian translation – Steam" width="320">

Unofficial Hungarian translation for the **Steam next-gen Windows edition of Metro 2033 Redux**.
Hungarian menus and subtitles, including translations of the newly added text. Weapon names remain in their original English form.

The installer can also hide the main menu advertising panel as an optional component, even without installing the Hungarian translation.

**Download:** [Releases](https://github.com/Harciropi/metro_2033_redux_nextgen_HUN/releases)

## Installation

**You do not need to install the original Hungarian translation separately.** This installer includes all required Hungarian language files; install it directly into the game folder.

1. Close the game.
2. Run `Metro2033Redux_NextGen_HU.exe`.
3. Check the game folder detected from your local Steam installation, or select it manually.
4. Select the components you want, then install them.
5. To use the Hungarian translation, select **English as the text language** in the game — menus and subtitles will appear in Hungarian.

## Changing components and uninstalling

Run the same EXE again. Components can be enabled or disabled individually, or removed completely. The installer restores the backed-up original files; after a successful complete uninstall, it also deletes its own backups. Your saved games and personal settings are preserved.

A game update may restore the modified files. If this happens, you may need to reapply the components or use an updated installer. The older legacy edition of the game is not supported; if you own that edition, use Lostprophet’s original Hungarian translation instead.
